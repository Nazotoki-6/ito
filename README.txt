ito CSVアプリ v6 完成版寄り

今回の改善
1. 順位をドラッグで並べ替え
   タブレット・スマホで名前カードを上下にドラッグできます。

2. 答えを1人ずつ発表
   最下位から1人ずつ、名前と数字を公開します。

3. PERFECT / 惜しい判定
   完全正解なら「PERFECT！」。
   正しい位置の人数に応じて「惜しい！」「あと少し！」などを表示します。

4. 秘密数字の安全表示
   数字表示中は次の人の名前を表示しません。
   数字を隠した後にだけ次の人が分かります。

5. お題を大きく表示
   数字確認が終わるまでお題は表示せず、全員確認後に大きく表示します。

6. 大きい順を強調
   100 → 1、1位＝100に近い、と画面上で分かりやすく表示します。

7. ROUND表示
   ROUND 1、ROUND 2…と表示します。

8. 履歴
   直近10ラウンドのお題・結果・正解順を端末内に保存します。

9. 効果音・振動
   ON/OFF可能。Web Audioと端末の振動機能を使います。
   端末やブラウザによって振動非対応の場合があります。

10. ゲーム中の参加者変更をロック
    ゲーム開始後は参加者設定を触れません。
    「ゲーム終了」で参加者選択へ戻ります。

従来機能
・参加者：ゆか、たけ、つね、ともみ、お母さん、お父さん
・初期ON：ゆか、たけ、つね、ともみ
・初期OFF：お母さん、お父さん
・数字確認順は毎ラウンドランダム
・数字は1〜100、重複なし
・お題500個
・1 / 100 基準表示
・topics.csv が読めないローカル起動では topics-data.js を使用

v7 オフライン対応 / PWA

追加ファイル
・manifest.json
・service-worker.js
・icons/icon-192.png
・icons/icon-512.png
・icons/apple-touch-icon.png

使い方
1. GitHub の Nazotoki-6/ito リポジトリへ、このZIP内のファイルをすべてアップロードしてください。
2. GitHub Pages のURLをオンライン状態で一度開いてください。
3. 画面に「オフライン準備OK ✓」と出ればキャッシュ完了です。
4. その後は機内モードでも起動できます。
5. iPad / iPhone は Safari の共有ボタン →「ホーム画面に追加」にするとアプリ風に起動できます。

注意
・最初の1回だけはインターネット接続が必要です。
・GitHubのURLではなく、GitHub Pagesの公開URLから開いてください。
・Service Worker は https のGitHub Pages上で動きます。index.htmlをfile://で直接開いた場合はPWAのオフライン保存は働きません。
・今後ファイルを更新した際は service-worker.js の CACHE_NAME
  （現在: ito-game-cache-v7-20260822）
  を v8 など新しい名前へ変更すると、古いキャッシュを確実に更新できます。


v7.1 改善①：順位決めの先入観をなくす

変更前：
・順位画面を開くと、参加者がランダムな順番ですでに並んでいた。

変更後：
・1位、2位、3位…の枠はすべて空の状態から開始。
・未選択メンバーの名前を、1位だと思う人から順番にタップして入れる。
・「1つ戻す」「最初から」で押し間違いを修正できる。
・全員を選択するまで「答え発表」は押せない。

これにより、最初に表示されたランダム順に判断が引っ張られる問題を防ぎます。

Service Worker CACHE_NAME:
ito-game-cache-v7-1-20260906


v7.2 改善②：ゲーム途中の完全自動保存

・ゲーム開始後の状態を端末の localStorage へ自動保存。
・Safariやホーム画面アプリを閉じても、次回起動時に「前回のゲームを再開」を表示。
・ROUND数、参加者、残りお題、現在のお題、秘密の数字、確認中の人、順位入力、答え発表の途中まで復元。
・秘密の数字を表示している最中に閉じた場合、再開時に数字は自動表示しない。
  同じ人の「数字を見る」画面から安全に再開。
・「ゲーム終了」で途中保存データを削除。
・「前回のゲームを破棄」で途中データだけ削除可能。

Service Worker CACHE_NAME:
ito-game-cache-v7-2-20260906


v7.3 改善③：使用済みお題の状態を永続保存

・お題の残り数を専用の localStorage に保存。
・ゲーム終了後も、Safariを閉じても、端末を再起動しても残り数を維持。
・例：残り327 / 500 の状態なら、次回も残り327問から開始。
・ゲーム途中の自動保存データを破棄しても、お題の使用済み状態は消えない。
・「ゲーム終了」を押しても、お題の使用済み状態は維持。
・「お題500個をリセット」を押したときだけ全500問へ戻る。
・お題を1つ引いた瞬間に進捗を保存するため、突然アプリを閉じても重複しにくい。

v7.4 改善④：ゲーム中の画面スリープ防止

・対応ブラウザでは、ゲーム中だけ Screen Wake Lock を有効化。

・ゲーム終了時は自動解除。
・Wake Lock非対応のブラウザでも、ゲーム自体は通常どおり遊べる。
・秘密の数字を表示したままアプリを離れた場合は、これまでどおり自動で隠す。

v7.5 改善⑤：誤タップ防止

重要な操作を1回のタップでは実行しないように変更。
専用の確認画面を表示してから実行します。

確認対象：
・ゲーム終了
・お題500個リセット
・前回ゲームの破棄
・履歴の全削除

通常のゲーム進行：
・数字を見る / 隠す
・順位選択
・答え発表
・次のROUND
などには余計な確認を追加していません。

確認画面では「キャンセル」を先に選びやすくし、
画面外タップやEscキーでもキャンセルできます。

【v8.5 人狼モード会話ルール更新】
・人狼モードは5ROUND固定。
・PERFECTを3回逃すと人狼の勝利条件を達成。途中終了はせず、5ROUND終了後に人狼を1人予想する。
・人狼を当てた場合は市民勝利。
・回答変更、質問、順位相談、他人の回答を上下に評価する発言はOK。
・「俺はかなり上」「真ん中より上」「80以上」など、自分の数字の位置を直接伝える・匂わせる発言は禁止。
